# VentureNest (Android first)
Designed for Yayra. The app is `www/index.html`; Capacitor wraps it.
1. Create a GitHub repo named VentureNest and upload ALL these files (keep the folders, including `.github/workflows`).
2. Open the Actions tab, pick "Build Android APK", press Run workflow.
3. When it finishes, open the run and download `VentureNest-Android-Debug-APK` (a ZIP containing `app-debug.apk`).
4. Send the APK to your phone, allow "install from this source", install.
Data is stored on the phone only. Export backups from More. Pages deploy comes later.
